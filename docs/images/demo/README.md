# InspectAI Demo Assets & Screenshot Guide

This directory houses verified application payloads and visual assets for the InspectAI portfolio demonstration video and documentation.

---

## 1. Verified Live Application Payloads (Authentic Programmatic Output)

The following authentic payloads were produced directly by `scripts/verify_live_demo.py` running against the frozen model artifacts:

- [`backend_health_response.json`](backend_health_response.json): Live output from `GET /api/v1/health` showing healthy system state, CPU execution, and loaded model components.
- [`openapi_specification.json`](openapi_specification.json): Official OpenAPI 3.1.0 schema generated by FastAPI containing registered schemas and endpoints.
- [`prediction_response_118.json`](prediction_response_118.json): Authentic inference and 1D Grad-CAM response for a 2,048-sample window from CWRU recording `118.mat` (Ball Fault).
- [`stream_packet_sample.json`](stream_packet_sample.json): Authentic WebSocket telemetry frame showing sequential packet metadata, timestamp intervals, and uncalibrated softmax distribution.

## 2. Screenshot Capture Checklist for Video Presenters

Because browser screenshot capture requires an interactive desktop display and graphical browser session, capture the following 6 genuine screenshots using your local browser:

| # | Filename | Target View & URL | Expected Content to Display |
| :-: | :--- | :--- | :--- |
| **1** | `01_streamlit_main_dashboard.png` | `http://localhost:8501` | Main Streamlit interface: sidebar controls, recording selection (`118.mat`), replay speed slider, and status banner. |
| **2** | `02_simulated_streaming_active.png` | `http://localhost:8501` | Active simulated replay in progress: dynamic waveform chart updating live at ~42.67 ms step interval. |
| **3** | `03_prediction_results_probabilities.png` | `http://localhost:8501` | Live telemetry cards: Window sequence counter, anomaly badge, and horizontal softmax probability bars. |
| **4** | `04_gradcam_attribution_viewer.png` | `http://localhost:8501` | Grad-CAM explanation section: 1D saliency heatmap overlaid across the 2,048-sample waveform highlighting transient impact peaks. |
| **5** | `05_fastapi_swagger_docs.png` | `http://localhost:8000/docs` | Interactive Swagger UI: FastAPI service title, `/api/v1/health`, `/api/v1/predict`, and Pydantic schemas. |
| **6** | `06_backend_health_json.png` | `http://localhost:8000/api/v1/health` | Raw browser JSON output showing `{"status":"healthy","model_loaded":true,"model_name":"VibrationCNN1D",...}`. |

### Step-by-Step Instructions to Capture:
1. Open two terminal windows.
2. **Terminal 1**: Start FastAPI:
   ```bash
   uvicorn backend.main:app --host 0.0.0.0 --port 8000
   ```
3. **Terminal 2**: Start Streamlit:
   ```bash
   streamlit run frontend/app.py --server.port 8501
   ```
4. In your browser:
   - Navigate to `http://localhost:8000/docs` and capture `05_fastapi_swagger_docs.png`.
   - Navigate to `http://localhost:8000/api/v1/health` and capture `06_backend_health_json.png`.
   - Navigate to `http://localhost:8501` and capture `01_streamlit_main_dashboard.png`.
   - Select recording `118.mat`, click **Start Simulation**, and capture `02_simulated_streaming_active.png` and `03_prediction_results_probabilities.png`.
   - Toggle **Compute 1D Grad-CAM Attribution** and capture `04_gradcam_attribution_viewer.png`.
5. Save all screenshots directly into `docs/images/demo/`.
